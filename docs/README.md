# Monolith user docs

Design docs for contributors live in `development/docs/`. This folder is for people using Monolith.

- `api/overview.md` — concepts, base URL, versioning, errors
- `api/rest.md` — REST for any language (curl examples)
- `api/websocket.md` — realtime + sync over WebSocket/SSE for any language
- `api/kotlin.md` — Kotlin / Android SDK
- `api/typescript.md` — TypeScript / JavaScript SDK
- `api/auth.md`, `api/rules.md`, `api/openapi-mcp.md`
- `guides/quickstart.md`, `guides/app-backup.md`, `guides/offline-sync.md`, `guides/docker.md`
