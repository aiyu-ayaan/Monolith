# Monolith Kotlin SDK

- `monolith-core` — pure Kotlin (KMP), Ktor client, kotlinx.serialization. No Android deps.
- `monolith-android` — Android library (AAR): offline store, background sync, secure token storage.

Maven coordinates (placeholder): `dev.monolith:monolith-core`, `dev.monolith:monolith-android`.
Docs: ../../docs/api/kotlin.md
